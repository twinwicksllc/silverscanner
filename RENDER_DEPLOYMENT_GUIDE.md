# SuperNinja Silver Scanner - Render Deployment Guide

## Overview
This guide will help you deploy the Silver Scanner to [Render](https://render.com), a modern cloud platform that's perfect for Flask applications.

## Prerequisites
- GitHub account with access to `twinwicksllc/silverscanner` repository
- Render account (free tier available)
- Your eBay Production API credentials (already configured in render.yaml)

## Why Render?

**Advantages for Silver Scanner:**
✅ Native support for Flask/Python applications  
✅ No timeout issues for long-running scans  
✅ Built-in SSL certificates  
✅ Automatic deployments from GitHub  
✅ Persistent storage for database  
✅ Cron jobs for automated scanning  
✅ Free tier available

### 1.3 Update Database Path for Render
Render uses a persistent disk, so we need to adjust the database path:

Edit `config.py`:
```python
# Change this line:
DATABASE_PATH = 'database/silver_scanner.db'

# To this (Render uses /opt/render/project/ as the base directory):
import os
DATABASE_PATH = os.path.join(os.environ.get('RENDER_PERSISTENT_DIR', '/opt/render/project/database'), 'silver_scanner.db')
```

## Step 2: Deploy to Render

### 2.1 Create Render Account
1. Go to [render.com](https://render.com)
2. Sign up or log in
3. Connect your GitHub account

### 2.2 Deploy Using render.yaml (Recommended)

1. Click **"New +"** button in Render dashboard
2. Select **"Existing repository"**
3. Search for and select `twinwicksllc/silverscanner`
4. Render will detect `render.yaml` automatically
5. Click **"Apply"** to create the service

### 2.3 Manual Deployment (Alternative)

If render.yaml isn't detected:

1. Click **"New +"** → **"Web Service"**
2. Connect your GitHub repository
3. Configure the service:

**Build & Deploy Settings:**
- **Name:** silver-scanner
- **Region:** Oregon (or nearest to you)
- **Branch:** main
- **Runtime:** Python 3
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `gunicorn app:app --workers 1 --bind 0.0.0.0:$PORT`

**Advanced Settings:**
- **Health Check Path:** `/`

**Environment Variables:**
Add all the variables from the render.yaml file (already configured)

**Persistent Disk:**
- **Name:** data
- **Mount Path:** `/opt/render/project/database`
- **Size:** 1 GB

To use `silver.techstart.com`:

1. In Render dashboard, go to your service
2. Click **"Custom Domains"**
3. Add `silver.techstart.com`
4. Render will provide DNS records to add:
   ```
   Type: CNAME
   Name: silver
   Value: [your-render-app-name].onrender.com
   ```

5. Add this CNAME record to your DNS provider
6. SSL certificate will be automatically configured

Check the Render dashboard for:

## Step 6: Configure Automated Scanning

The `render.yaml` includes a cron job that runs scans every 4 hours.

### Cron Schedule
- **Current:** Every 4 hours (`0 */4 * * *`)
- **Format:** Minute Hour Day Month Weekday

### Adjust Cron Schedule (Optional)
Edit `render.yaml`:
```yaml
crons:
  - name: automated-scan
    schedule: "0 */2 * * *"  # Every 2 hours
    # Or use specific times:
    # schedule: "0 9,15,21 * * *"  # 9am, 3pm, 9pm
    command: python -c "from app import deal_scanner; deal_scanner.perform_scan()"
    service: silver-scanner
```

### Monitor Cron Jobs
In Render dashboard:
1. Go to your service
2. Click **"Cron Jobs"** tab
3. View execution history and logs

## Step 10: Troubleshooting

### Issue: Deployment Fails
**Solution:**
- Check build logs in Render dashboard
- Verify all dependencies in `requirements.txt`
- Ensure `app.py` and `config.py` are present
- Check for syntax errors in Python files

### Issue: 500 Internal Server Error
**Solution:**
- Check application logs in Render dashboard
- Verify database path is correct for Render
- Check environment variables are set correctly
- Ensure all modules are properly imported

### Issue: Database Errors
**Solution:**
- Verify persistent disk is mounted at `/opt/render/project/database`
- Check database file permissions
- Ensure database directory exists

### Issue: Scan Timeout
**Solution:**
- Increase timeout in Render dashboard (Settings → Advanced)
- Reduce number of search terms or items per scan
- Optimize scan performance

### Issue: Cron Job Not Running
**Solution:**
- Check cron job logs in Render dashboard
- Verify cron schedule syntax is correct
- Ensure service is running and healthy
